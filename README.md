# AI Productivity Toolkit 🚀

A comprehensive collection of prompt engineering templates, structured JSON extraction workflows, and automation scripts. Includes zero-shot/few-shot prompting techniques, reusable developer templates, and Google Colab execution scripts.

## 🛠️ What's Inside?
* **Zero-Shot & Few-Shot Prompts:** Optimized templates for classification, generation, and extraction.
* **Structured Outputs:** Enforcing strict JSON outputs from LLMs for programmatic parsing.
* **AI Productivity Workflows:** Automated templates for summarization, email drafting, and code debugging.

## 📂 Folder Structure
* `prompts/`: Reusable Markdown prompt templates for daily developer tasks.
* `colab/`: Python code snippets utilizing LLM APIs for automated tasks.
